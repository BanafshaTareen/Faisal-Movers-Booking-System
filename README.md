# Faisal Movers Ticket Reservation System

A desktop-based ticket reservation and management system developed using **C# Windows Forms** and **Microsoft SQL Server** as a university Visual Programming project.

The application is designed to manage bus operations, routes, schedules, passengers, and ticket reservations through a graphical desktop interface.

## Features

- User login system
- Role-based access for Admin and Clerk
- Bus management
- Route management
- Schedule management
- Passenger record management
- Ticket reservation
- Available schedule selection
- Seat selection
- Passenger search using CNIC
- View and search reservations
- Reservation receipt/report generation
- SQL Server database integration

## Technologies Used

- C#
- .NET Windows Forms
- Microsoft SQL Server
- ADO.NET
- Visual Studio
- RDLC Reports

## Database

The system uses a relational SQL Server database containing tables for:

- Users
- Buses
- Routes
- Schedules
- Passengers
- Reservations

The database structure was designed to support the relationships between passengers, routes, schedules, buses, and reservations.

## Project Purpose

This project was developed to apply concepts of desktop application development, database connectivity, CRUD operations, form validation, relational database design, and report generation in a practical reservation system.

## Running the Project

1. Open the project in Visual Studio.
2. Configure Microsoft SQL Server.
3. Create the required database and tables.
4. Update the database connection string in `App.config` according to your SQL Server configuration.
5. Build and run the application from Visual Studio.
